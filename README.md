# 🎬 E-FLIX | 구독형 ERP 시스템

## 📌 프로젝트 개요

**E-FLIX**는 소기업 및 스타트업을 위한 **구독 기반 ERP(전사적 자원 관리)** 시스템입니다.  
관리자는 모듈형 ERP 기능을 구독하여 기업의 회계, 인사, 재고, 영업 등을 손쉽게 통합 관리할 수 있으며,
기업은 필요한 기능만을 선택적으로 이용할 수 있어 **비용 효율성과 확장성**을 제공합니다.

## ✅ 주요 기능

### 🔐 인증 & 보안
- **회원가입/로그인**: 정규식 1차 검증, SHA-256 암호화, Spring Security 기반 인증
- **권한 관리**: SecurityFilterChain을 통한 메인/서비스 페이지 접근 제어

### 👥 회원 관리
- **회원**: 프로필 관리, 회사 정보 등록/수정, 구독 관리
- **관리자**: 회원/회사/구독/문의 통합 관리, 문의 답변 시스템
- **문의 시스템**: 고객 문의 등록 및 관리자 답변 처리

### 🏢 인사 관리 모듈
- **부서 관리**: 트리 구조 부서 조직도, 부서별 사원 관리
- **사원 관리**: 사원 정보 등록/조회/수정, 사원별 상세 정보 관리
- **근태 관리**: 출퇴근 기록, 근태 수정 요청 처리
- **휴가 관리**: 휴가 신청 및 승인 시스템
- **급여 관리**: 급여 항목 설정, 급여 계산 및 명세서 출력

### 💰 회계 관리 모듈
- **계정과목 관리**: 표준 계정과목 체계 지원
- **전표 처리**: 일반전표, 매입매출전표 CRUD, 전표번호 자동 생성
- **자동 분개**: 급여 전표 자동 처리, 계정과목별 자동 분개
- **장부 관리**: 거래처원장, 매입매출장 조회 및 집계
- **재무제표**: 재무상태표, 손익계산서 자동 생성

### 📦 재고 관리 모듈
- **창고 관리**: 다중 창고 등록/관리, 창고간 제품 이동 추적
- **입고 관리**: 제품 입고 처리, 자동 제품 생산 스케줄링 (프로시저)
- **출고 관리**: 출고 의뢰서 기반 출고 처리, 출고 이력 관리
- **재고 조회**: 실시간 재고 현황, 창고별 재고 조회

### 📈 영업 관리 모듈
- **견적서 관리**: 견적서 생성/수정/삭제, 거래처별 견적 이력
- **주문서 관리**: 견적서 연동 주문 생성, 거래처 여신 정보 연동
- **출하 관리**: 주문서 기반 출하 의뢰서 생성, 재고팀 연동

### 🔧 시스템 기능
- **구독 관리**: ERP 모듈별 구독 서비스, PortOne 결제 연동
- **보고서**: JasperReports 기반 계약서/명세서 자동 생성
- **대시보드**: 구독 현황, 사용자 통계, 모듈별 사용 현황

### ⚙️ 기술 인프라
- **CI/CD**: Docker, Jenkins, Apache Maven 통합 배포
- **클라우드**: AWS 서버 및 DB 구축
- **형상관리**: Git 기반 소스코드 관리
